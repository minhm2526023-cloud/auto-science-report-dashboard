# 📊 Dashboard Phân tích Dữ liệu & Sinh Báo cáo Khoa học PDF Tự động

## 1. Giới thiệu Mini-project
Dự án xây dựng ứng dụng Web tương tác bằng **Python** và **Gradio**, tự động hóa quy trình từ khâu làm sạch dữ liệu thực nghiệm, trực quan hóa biểu đồ thống kê, huấn luyện mô hình phân loại cho đến xuất bản báo cáo khoa học định dạng **PDF** hoàn chỉnh.
